### Report Details

- **File:** US-E-Commerce-Analytics.pbix
- **Format:** Power BI Desktop (.pbix)
- **Data Mode:** Import
- **Pages:** 5
- **Measures:** 24
- **Data Source:** SQL Server Gold Layer
- **Model:** Kimball Star Schema

### Dashboard Pages

1. **Executive Overview**
2. **Sales & Profitability**
3. **Customer & Geography**
4. **Operations & Fulfillment**
5. **Payments & Customer Experience**

The dashboard focuses on revenue, profitability, customers, geography, fulfillment performance, payments, and customer experience.
